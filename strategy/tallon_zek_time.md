Phase 4. [Plane of Time](/strategy/plane_of_time). Kill **Tallon Zek** before **[Vallon Zek](/strategy/vallon_zek_time)** so you have room. Do not aggro Vallon.

He is **Unslowable**. Rampage. Dual Wield. Hits 3040. Attack delay 11. Assist 100. 1.4M HP.

**Barb of Tallon** has four versions (Targeted AE, Cold -100 40% slow + 40% snare DD / Fire -100 DD / Disease -100 300/tick + AC -147 + 60% agro / Poison -100 single DD).

**Tallon's Balance** is a PBAE (-300 all resists, Unresistable, 60s recast).

**Planeshift** is a PBAE (50% mana cost, Magic -200, 7 min recast). Pull it before the raid engages if you want it gone.

**Strategic Blow** is a single (2000 DD + 500/tick + 8s stun, Cold -200, 7 min recast).
